Sales Context Graph

Three untrusted-shaped sources — Salesforce, Gong, Showpad — become tenant-isolated, evidence-backed Claim nodes in Neo4j, then a bounded, scored selection served to one recommendation workflow. Nothing is asserted without a source segment and a character span behind it.

Anatomy of a Claim

A sentence in a transcript never becomes a graph fact directly. It becomes evidence — traceable back to the exact character span it came from, and coexisting peacefully with anything that contradicts it until arbitrated.

Tenant isolation, structurally enforced

Not a convention — GraphExecutor.tenant_query() rejects any Cypher whose matched nodes aren't scoped by workspace_id, including full-text and vector procedure calls.

Workspace A

workspace_id: acme-01

Account "Volkswagen Group", Contact "Elena Popescu" — same display name intentionally duplicated in Workspace B to prove the boundary holds under collision.

Workspace B

workspace_id: globex-02

Its own "Volkswagen Group", its own "Elena Popescu" — structurally unreachable from Workspace A's reads, writes, full-text, or vector queries.

GraphExecutor → unscoped MATCH → rejected before execution
Dependency direction

One-way. api/ depends on everything below it; src/domain depends on nothing in this repo — no Neo4j import, no I/O.

api/
FastAPI routes — parse request, call a use case, shape response. No business logic.
src/usecases/
objection → unviewed content, and the seller-experience layer (Q&A, digest, narrative summaries).
src/context_graph/
bounded, scored Claim selection for one scope — node/token budget, diversity cap.
src/resolution/ · src/review/
deterministic rules, candidate generation, scoring, decision policy, async human review.
src/extraction/
windowing + extraction provider Protocol — fixture and LLM implementations, same interface.
src/ingestion/
source adapters + reconciliation — identical / changed / deleted handled explicitly.
src/graph/
tenant-safe execution modes, schema/indexes, migrations, one repository per aggregate.
src/domain/
pure Pydantic v2 contracts + deterministic ID hashing. Nothing depends on it; it depends on nothing.
